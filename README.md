# CodeCollab

A collaborative code editor with built-in chat — all in the browser. Pure HTML, CSS, and JavaScript with no dependencies.

## Pages

- **Landing Page** (`index.html`) — Hero section, feature cards, and call-to-action
- **Code Editor** (`editor.html`) — Multi-file editor with tabs, line numbers, file explorer, collaborator avatars, and a mini chat panel
- **Team Chat** (`chat.html`) — Channel-based chat with code block support, direct messages sidebar, and auto-resizing input

## Getting Started

Open `index.html` in your browser — no build step required.
